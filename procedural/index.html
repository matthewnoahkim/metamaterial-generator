How it works

Candidates come from a stochastic generator (smoothed Gaussian-random-field topologies plus strut/lattice motifs), optionally folded to enforce symmetry. Each is scored by the same homogenization algorithm used to label the project dataset, ported to JavaScript and validated against the Python solver.

Auxetic note: The "Auxetic" goal mixes in a rotating-squares family (rigid squares joined by small corner hinges) drawn directly on the evaluator's 24×24 grid, so the displayed cell is exactly what the physics sees. Measured ν reaches about −0.65, most reliably at volume fraction 0.40–0.55; the number shown is always the homogenized value, not the target. The symmetry setting does not apply to this family (the rotation pattern would be destroyed by mirror folding).
